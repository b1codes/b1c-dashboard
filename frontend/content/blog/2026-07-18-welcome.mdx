# Welcome to the Dev Log

This is where I'll log what I'm learning as I build each project under the B1C umbrella.

Each post is tied to a project and captures:

- **What I built** — the feature or system I worked on
- **What I learned** — the concept, pattern, or tool I deepened my understanding of
- **What I'd do differently** — honest retrospective notes

Posts are written in MDX, which means I can embed live React components directly inside prose — useful for interactive architecture diagrams, animated demos, or side-by-side code comparisons.

## Why a dev log?

Building in public creates accountability and produces a durable record of growth. Recruiters and collaborators can follow the thinking, not just see the polished output.
